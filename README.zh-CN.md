# AI 文档机器人

窗口右下角住着一只小机器人。

- **单击**：用思源内置 AI 总结当前文档。
- **双击**：批量总结当前笔记本中的文档，并生成一篇汇总文档。
- **右键**：打开同样的操作和设置。

单篇总结会先弹出预览，可选择**插到开头**、**追加到末尾**、**复制**或**丢弃**；写入时自动加 `## AI 摘要` 标题和结尾分隔线。

可选后处理：

- 总结后自动写入 3–5 个 AI 标签。
- 自动添加确定性的题头图（内联 SVG，无网络请求）。

使用 Vite 8 + TypeScript + Svelte 5 重建。

## 要求

- 思源桌面端 3.7.0 及以上。
- 已在「设置 → AI」中配置可用的模型。

## 数据影响

- 读取：当前文档的 Markdown、文档属性、当前笔记本的文档列表。
- 写入：仅在你确认后写入摘要、标签和题头图。
- AI 请求只发往本机思源内核。

## 开发

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
